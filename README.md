# 游戏内数据库连接池与分库分表系统

## 项目描述

游戏内数据库连接池与分库分表系统的bug修复项目。核心模块 `db/pool.py` 存在多个已知bug，需要修复后使测试全部通过。

## 已知问题

- 连接池完全没做每次查询都新建连接
- 分库分表完全没做所有数据都在一个库
- 读写分离完全没做读和写都走主库
- 负载均衡完全没做从库空闲主库忙死
- 事务管理完全没做分库后事务不原子

## 运行测试

python -m pytest tests/test_db_pool.py -q
